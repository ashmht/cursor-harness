# Documentation Loops

| Need | Skill |
|---|---|
| End-to-end artifact routing | `loop-artifact` |
| RFC, tech spec, ADR, or architecture decision | `loop-design-doc` |
| Tutorial, onboarding, or concept explanation | `loop-concept-explainer` |
| Durable visual reference page | `loop-html-doc` |
| Stress-test a proposal | `loop-devils-advocate` |
| Synchronize docs with code | `loop-docs-sweep` |
| Presentation or keynote | `wow-deck` |
| Architecture diagram | `architecture-diagram` |

## Voice map

| Artifact | Rule |
|---|---|
| RFC, alignment, recommendation | `larson-voice.mdc` |
| Tech spec, ADR, glossary | `fowler-voice.mdc` |
| Tutorial or README | `julia-evans-voice.mdc` |
| Incident or investigation | `pragmatic-engineer-voice.mdc` |
| ROI or business case | `patio11-voice.mdc` |

Run `humanizer` last on human-facing prose. Read the selected skill before
starting; each loop owns its stop criteria and verification.
