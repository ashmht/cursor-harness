# Provenance

The repository combines original personal workflows with adapted public
material. Adaptations have been generalized for this harness.

- `architecture-diagram`: Cocoon AI, MIT license as declared in its skill
  metadata.
- `compact-chat`: adapted from
  [douglac/compact-chat](https://github.com/douglac/compact-chat).
- `humanizer`: adapted from
  [Aboudjem/humanizer-skill](https://github.com/Aboudjem/humanizer-skill).
- `reddit-post-writer`: adapted from
  [niveshdandyan/reddit-post-skill](https://github.com/niveshdandyan/reddit-post-skill);
  its license is retained in the skill directory.
- `technical-writing`: an original rewrite informed by the public workflow in
  [richtabor/agent-skills](https://github.com/richtabor/agent-skills). No
  upstream files are vendored because that repository exposes no discoverable
  license.
- `loop-*` workflows cite the relevant
  [Forward Future Loop Library](https://signals.forwardfuture.ai/loop-library/)
  entry in each skill.

Voice rules summarize public writing patterns and link or name their source
authors. They are guidance, not copies of source articles.
